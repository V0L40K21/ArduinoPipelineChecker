# GitLab Pipeline Monitor (ESP32 + Node.js)

Небольшая система, которая отображает статус последних GitLab-пайплайнов на OLED-экране, используя ESP32 и локальный Node.js-сервер.  
Проект создан для того, чтобы **иметь компактный настольный монитор CI/CD**, который автоматически подаёт данные с GitLab API и показывает их в реальном времени.

---

## ✨ Возможности

- Получение списка последних проектов пользователя из GitLab API
- Проверка их пайплайнов за последний период
- Возврат удобного JSON-ответа
- Отображение названий проектов и статуса пайплайна на OLED 128×64
- Значки состояния (успех / ошибка / в процессе / нет пайплайнов)
- Автоматическое подключение к Wi-Fi с отображением процесса на экране

## 🖥 Как работает система

#### 1. Node.js сервер

    • запускается локально (обычно на ПК или сервере),
    • по `GET /check` получает список проектов пользователя с GitLab,
    • затем проверяет пайплайны каждого проекта,
    • возвращает массив вида:

```json
[
  { "title": "MyProject", "status": "success" },
  { "title": "Backend", "status": "failed" },
  { "title": "Frontend", "status": "running" }
]
```

#### 2. ESP32

    •	подключается к Wi-Fi,
    •	делает HTTP-запрос к Node-серверу,
    •	парсит JSON,
    •	рисует на экране список проектов и иконки статусов.

## ⚙️ Настройка Node.js сервера

#### Установка зависимостей

```bash
cd node
npm install
```

#### Необходимые переменные окружения (.env)

```bash
SERVER_PORT=3000
GITLAB_HOST=https://gitlab.com
GITLAB_TOKEN=<ваш токен>
```

#### Запуск сервера

```bash
npm run start
```

#### После запуска сервер будет доступен по:

```bash
http://localhost:3000/check
```

---

## ⚙️ Настройка ESP32

Перед прошивкой нужно определить параметры Wi-Fi и сервер в файле env.h:

```c
#define WIFI_SSID "your_wifi"
#define WIFI_PASS "your_password"

#define SERVER_HOST "your server IP"
#define SERVER_PORT 3000
#define SERVER_PATH "/check"
```

После загрузки ESP32:
• подключается к Wi-Fi,
• выводит IP-адрес,
• запрашивает данные с Node.js,
• рисует их на экране.

### 🖼 Пример отображения на OLED

```
1. Backend     [✓]
2. Frontend    [✗]
3. Mobile      [...]
4. API         [–]
```

Иконки берутся из файла icons.h (в проекте).
